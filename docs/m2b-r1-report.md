## R2 · 章节体系一致性（采用方案②）

### 所选方案

**方案②：对照版撤掉章节页体系（页码守恒）**，章节页族留给未来正式多章 deck（≥3 章时启用完整体系）。

### 理由

| 考量 | 方案① 补齐 01/02/04 | **方案② 撤掉（选用）** |
|---|---|---|
| 页数影响 | 需 +3 页 → **24 页，超出 T-03 的 18–22 上限** | 21 页保持不变 |
| 内容影响 | 无 | 无（P09/P20 恢复原内容页） |
| 结构自洽 | 5 章完整体系 | 无章节页 → 不存在"半体系"问题 |
| 与 R1 关系 | R1 已需恢复 P09，若再做章节页将双重占页 | **R2 与 R1 同时修复，一次到位** |
| 适用场景 | 正式多章 deck | **对照实验**（本次定位） |

**关键约束**：T-03 要求 18–22 页。方案① 会突破上限，方案② 既满足页数约束又消除
"半章节体系"的不自洽——**R1 与 R2 的修复在此方案下是同一动作**。

### 落地结果

- P09 从 `section-hero` → `v1/layered-arch`（恢复架构内容）
- P20 从 `section-hero` → `v1/decision-3`（恢复决策页）
- **章节页数量：0**（原为 2，半体系问题消除）

## R4 · subtier 第四类 `value`（含硬止损触发）

### 实现

`classify_subtier` 新增 `value` 类：**数字 + 可选短单位**（`_looks_like_value`）。
分类器单元测试 **20/20 通过**（含 6 个 value 正例、3 个 short 反例）。

### 靶场结果与止损触发

| 阶段 | t03-v2 结果 |
|---|---|
| 修复前（T-M2B 交付时） | P1 = **3** |
| 加入 `value` 类后 | P1 = **3**（**未改善**） |

**为什么未改善**：T-03 的验收指标值是**文字**（`秒级返回`、`抽查全对`、`周活跃达标`），
不是数字，因此**无法归入 `value`**，仍与条目名同属 `short`。

**→ 触发硬止损条款**（"value 引入后再出现任何 free-design 误报 → 无条件切换主标题通道"）。

### 切换实现：页面主标题通道

**新增 `main_title_channel(titles)`**：free-design 路径下，
**每页只取字号最大的那个标题候选**参与比较（同字号取较短文本），
再对这些"页主标题"做同页 spread 与跨页偏离检测。

- **占位符路径完全不变**（role 是 ground truth）
- **止损依据写在代码 docstring 中**（三重机会已用完的完整说明）

### ⚠️ 止损的已知代价（如实报告）

**`samepage_3` 回归失效**：该样张是"**同一页** 28pt×2 + 24pt×1"。
主标题通道每页只取最大字号（28pt），因此该页的 24pt **不再参与任何比较** → 不再报告。

**这是止损切换的必然代价，不是缺陷**：
- 主标题通道的设计前提就是"每页只关心它的主标题"
- 它用**同页非主标题的检测能力**换取了**误报的彻底消除**
- 若未来需要"同页多标题一致性"，应作为**独立功能**设计（不回到特征方案）

**建议**：把 `samepage_3` 样张从"回归基线"改为"已知能力边界"记录，
避免后续执行者误判为回归失败。
