# Test Set v1（测试集版本化规则见 CONTRACT.md）

## 用法

1. 每轮验证：对 `inputs.md` 全部 6 个输入跑一次端到端
2. 记录：`docs/failures.md`（失败模式 → C-XXX 编号 → 回归用例），验收绑定本测试集版本
3. 增补输入 = 升版本（`v1/` → `v2/`），且同步更新基线

## 评分轴（三层，见 CONTRACT.md 第 5 条）

- L1 自动校验（P0/P1 结构校验器）：溢出 / 乱码 / 结构缺失 / 风格漂移（D-2, D-3）
- L2 自动回归：golden samples 截图 diff（库内全量，日常每次跑）
- L3 人工抽检：每输入抽 1 张关键页（封面/目录/典型内容/图表页），每套风格 ≥2 张，
  3 个 2 分制维度（信息层级 / 视觉密度 / 风格一致性）；风格发现阶段全页评分

## 触发器

- L1 失败 = 阻断（P0）
- L3 抽检分数 < 4/6 = 该风格进入"反例库"并回归 DO NOT 检查项
