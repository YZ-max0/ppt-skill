## 执行

1. **A/B/B2/C 完整导演流程**（B2 硬门禁）+ **评审卡挂载**（§8 的 5 视角：逻辑/受众/风险/标题/缺失）——
   评审卡产出写入报告（挑出的问题与修改记录）
2. **质询应答设计**：5 个质询点 → 逐条设计"应对页"（质询-应对-证据 三栏结构或对照表）；
   证据类页优先用 `evidence-wall` / 表格 / 图表
3. **页面配方**（20 页）：封面 → 项目回顾 → 目标与达成 → 成果数据（图表）→ 不足与归因 →
   **5 个质询应答页组**（核心）→ 经验沉淀 → 下一步 → 收尾
4. **质检四道全过** + 交付 `docs/e2e-06-report.md`（含评审卡记录 + 质询应答映射表）
