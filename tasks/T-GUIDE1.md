> 来源：用户实测前三条反馈——①六输入模板门槛高；②需要可跳过的引导流程；③不选快速 = 尽可能高质量。

## 交付物 A · `deltas/intake-guide.md`（引导协议，≤200 行）

### 1. 入口一问（用户界面收敛为二分）

```
"这份 PPT：是要快，还是要尽可能做好？"（默认推荐：尽可能好）
```

### 2. "要尽可能好"分支 = 质量协议

| 项 | 策略 |
|---|---|
| 流程深度 | 按内容量伸缩：**≤12 页 → 轻量导演稿；>12 页 或 重要场景 → 完整导演式（A/B/B2/C）** |
| 质检强度 | **不打折**：四道自动闸 + 渲染目视 + **B3 评审卡默认挂载** |
| 视觉 | 展示 2-3 个视觉候选（看图选）；用户委托时用视觉增强版——不得默认克制版 |
| 演讲稿 | 演讲场景 → 询问逐字稿/提词卡；材料场景 → 提词卡默认 |

### 3. "要快"分支 = 轻量通道

默认值 + 标注假设（沿用 director.md §7 快速通道），跳过其余引导。

### 4. 引导原则（写入协议，AI 行为规范）

1. **术语禁令**：问题用场景语言（"给领导的重要汇报吗？"），禁"导演式/骨架/视觉增强"等内部术语
2. **跳过永远在**：每个问题都有"其他你来定"选项；用户跳过 → 默认 + 标注假设
3. **一次最多 3 问**：超出则按默认推进，后续再调
4. **能默认不问**：页数/时长/风格若可推断，不问，做默认注明
5. **自然语言优先**：用户一句话进来 → 缺口追问协议（只问缺的关键项）

### 5. 示例对话（两个完整走查，作为验收样本）

- 例 1："帮我做一份下周团队周报"（一句话 → 追问 → 快速）
- 例 2："下周要给分管领导汇报平台建设方案"（一句话 → 追问 → 质量协议 → 视觉候选展示）
