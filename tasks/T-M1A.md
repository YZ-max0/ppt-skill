## 战略背景

E2E 首跑基线：**36 分钟 = 33 分钟人工 + 10 秒机器**，瓶颈在"手写 SVG 25 分钟 + 契约修正 8 分钟"。
本卡目标：沉淀一批**已验证合规的版式骨架**，把"每页从零手写"变为"选版式 + 机械填充"，
实测压缩幅度（目标：6 页 deck ≤15 分钟，压缩 ≥50%）。

**路线决策（指挥官）**：v0 采用"合规 SVG 骨架 + 填写契约"轻量形态（立即可用、立即测量）；
base 原生 `create-layout` workspace 化升级留作 M2+ 候选（不阻塞现在）。

## 交付物 A · 资产库（进 repo，SVG 为文本资产）

`deltas/layout-assets/v0/`：

| 骨架 | 页型 | 基于 |
|---|---|---|
| `cover.svg` | 封面（标题+副题+汇报信息行） | T-01 P01 |
| `bullets.svg` | 要点列表（标题+3-4 条带强调词） | T-01 P02 |
| `two-col-compare.svg` | 双栏对比（风险/对策或 A/B） | T-01 P03 |
| `timeline.svg` | 时间轴/计划（3-4 节点） | T-01 P04 |
| `kpi-hero.svg` | 数据大字（1-3 个关键数字） | T-01/T-02 预判 |
| `closing.svg` | 结尾收束（总结句+呼吁） | T-01 P06 |

+ `CONTRACT.md`：每骨架的槽位定义（占位标记、字数上限、可选项、适配页型）。

**骨架硬标准**（吸收 C-001/C-003/W-5 教训，写入 CONTRACT）：
1. 根级 `<g>` 必带 `data-pptx-bounds`；整页背景独立组；多行文本单 `<text>`+多 `<tspan>`
2. 根带 `data-pptx-page-role`；字号只用既有档位（48/28/24/18 等）
3. 占位文本用统一标记（如 `【标题】`）+ 示例；**填充时必须全替换**（见验收）
4. 每个骨架必须先过 `svg_quality_checker --quick-generate --stage final` **零 blocking 才入库**
