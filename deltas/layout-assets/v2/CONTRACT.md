# 版式资产库 v2 · 填写契约（图表族 + 视觉锚点族）

> 位置：`deltas/layout-assets/v2/` ｜ 前置：v0/v1 基础契约见 `../v0/CONTRACT.md`
> 本文件只定义 **v2 新增的 8 个骨架**；v0 的通用规则（占位标记、填充流程、硬标准）继续生效。
> 状态：8/8 通过 `svg_quality_checker --quick-generate --stage final`，blocking 0 / introduced 0。

## 1. 通用约束（继承 + 新增）

继承 `../v0/CONTRACT.md` 全部硬标准（bounds / page-role / 单 text 多 tspan / 既有字号档位 /
checker 零 blocking / 最坏文案验证 / **层级字号差 ≥6pt**），并新增：

**v2-1 · 图表数据必须来自既有事实**
图表骨架只做"数据 → 几何"的**映射**，不得引入未在任何来源出现过的数字。
填充时须在导演稿/来源中能指认该数字。

**v2-2 · 语义色系统不得破坏**
- `#002FA7`（IKB 蓝）= 正文/主色/正向数据
- `#FF6B35`（橙红）= 风险/警示（仅风险类骨架使用）
- `#0A0A0A` 深色 = 锚点页背景（cover-bold / section-hero / decision 类）
- 灰阶 `#737373` / `#F0F0EE` / `#E2E8F0` / `#FFFFFF`
禁止为"更好看"引入新的强调色或改变既有语义。

**v2-3 · 增强页与普通页的可读性平衡**
v2 锚点页（深色/大色块）是**视觉锚点**，用于封面、章节、决策、金句；
普通内容页保持白底可读。**不得把普通内容页改成锚点页**，否则全篇失去节奏对比。

## 2. 图表族（4 个）

### 2.1 `bar-chart.svg` — 柱状对比（≤6 柱，本骨架 4 柱）

| 槽位 | 元素 | 字号 | 说明 |
|---|---|---|---|
| `【页面标题】` | x=80,y=90 | 40pt Bold | 页面标题 |
| `【柱N名称】` | 柱下 x=中心,y=546 | 22pt SemiBold | 类别名，≤6 字 |
| `【柱N值】` | 柱上 x=中心,y=192起 | 28pt Bold | 数值 + 单位，≤6 字 |
| `【图表说明】` | x=120,y=640 | 18pt | 口径/合计说明 |

**数据→几何映射规则**：
- 基线 y=500，最大柱高 290px（对应最大值）
- **柱高 = 值 / 最大值 × 290**，向下取整到整数像素
- 柱宽 130px，柱间距 230px（x 起点 190 / 420 / 650 / 880）
- **最大值定高**：数据中最大项占满 290px；其余按比例
- 数值标签置于柱顶上方 18px（28pt 文字基线）
- 只用 1–3 柱时删除多余柱组（`<rect>` + 2 个 `<text>`）

**本骨架已用数据（T-03）**：40/20/12/8 万 → 290/145/87/58px

### 2.2 `line-chart.svg` — 趋势折线（≤8 点，本骨架 3 点）

| 槽位 | 元素 | 字号 |
|---|---|---|
| `【页面标题】` | x=80,y=90 | 40pt Bold |
| `【点N】` | 轴下方 y=520 | 22pt SemiBold |
| 数值标签 | 点上方 24px | 24pt Bold |
| `【图表说明】` | x=120,y=630 | 18pt |

**数据→几何映射规则**：
- 绘图区 x∈[160,1120]，y∈[200,500]（基线 y=500）
- **点 x = 160 + (i/(n-1)) × 960**（均匀分布）
- **点 y = 500 - (值 / 最大值) × 300**
- 折线 `stroke-width=4`，关键点 `<circle r=9>`
- 区域填充可选（本骨架未启用，保持克制）

**本骨架已用数据（T-03）**：80/35/10 万 → 累计净投入下降趋势

### 2.3 `donut-chart.svg` — 占比环形（≤4 段，本骨架 2 段）

| 槽位 | 元素 | 字号 |
|---|---|---|
| `【页面标题】` | x=80,y=90 | 40pt Bold |
| 中心主数据 | cx=360,cy=368 | 56pt Bold |
| `【中心标签】` | cx=360,cy=410 | 20pt SemiBold |
| `【图例N】` / `【图例N值】` | x=700 | 24pt / 18pt |
| `【图表说明】` | x=120,y=645 | 18pt |

**数据→几何映射规则**：
- 圆心 (360,380)，半径 160，环宽 56（`stroke-width`）
- 圆周长 `C = 2π×160 ≈ 1005`
- **每段 `stroke-dasharray = 占比×1005  1005`**，用 `transform="rotate(-90 360 380)"` 从 12 点方向起始
- 后续段用 `rotate(<累计角度-90> 360 380)` 定位
- 段色：主色 `#002FA7`，次色 `#4A6FD4`（同色系浅一档，**不引入新色相**）
- 图例色块 `20×20`，与扇区色一致；图例垂直间距 110px

**本骨架已用数据（T-03）**：60 万 / 20 万 → 502/1005 与 251/1005

### 2.4 `comparison-bars.svg` — 横向对比条（≤5 项，本骨架 3 项）

| 槽位 | 元素 | 字号 |
|---|---|---|
| `【页面标题】` | x=80,y=90 | 40pt Bold |
| `【条目N名称】` | x=120，行 y=240/340/440 | 24pt SemiBold |
| `【条目N值】` | x=1180 **右对齐** | 24pt Bold |
| `【图表说明】` | x=120,y=645 | 18pt |

**数据→几何映射规则**：
- 条起点 x=360，条高 34px，条间距 100px
- **条长 = 值/最大值 × 最大可用长度**（本骨架最长 800px）
- 左侧有垂直基准线（x=360, 高 300）
- 数值标签**必须 `text-anchor="end"` 右对齐到 x=1180**（否则长文本越出 canvas）
- 条目名 ≤ 8 字，值 ≤ 6 字

**本骨架已用数据（T-03）**：三项指标达成水平（示意性条长）

### 3.1 `cover-bold.svg` — 强化封面

| 槽位 | 元素 | 字号 | 上限 |
|---|---|---|---|
| `【标题】` | x=560,y=330 | **52pt Bold** | **≤12 字**（实测上限） |
| `【副标题】` | x=560,y=410 | 24pt | ≤22 字 |
| `【汇报单位】` | x=560,y=600 | 22pt | — |
| `【周期】` | x=560,y=640 | 22pt | — |

**构成**：左侧 520px 宽 IKB 蓝色块 + 白色分隔线 + 右侧深色区超大标题；
右下两条短色条作为几何装饰。
**注意**：主标题 52pt 时可用宽度 720px，**实测上限 12 个汉字**（含标记字符）。
> 这是"最坏文案验证"暴露的真实约束：骨架初版 72pt 在真实 11 字标题下溢出，

### 3.2 `section-hero.svg` — 章节封页

### 3.3 `evidence-wall.svg` — 证据墙（4 格矩阵）

## 4. 混用规则（v0 / v1 / v2 并存）

v2 不是替代品，而是**增强件**。推荐搭配：

| 页型 | 推荐骨架族 | 说明 |
|---|---|---|
| 封面 | **v2 cover-bold** | 增强首因效应 |
| 章节过渡 | **v2 section-hero** | 提供节奏锚点 |
| 决策/请求 | **v2 section-hero**（换序号）或 v1 decision-3 | 二选一，同 deck 内保持一致 |
| 数据/对比 | **v2 bar-chart / comparison-bars** | 替代纯文字列表 |
| 证据汇总 | **v2 evidence-wall** | 替代三卡并列 |
| 结尾主张 | **v2 quote-hero** | 替代普通收尾 |
| 其余内容页 | v0 / v1 骨架 | **保持白底可读** |

**节奏建议**：锚点页（深色/大色块）之间至少间隔 3–4 页普通页，
避免连续深色造成视觉疲劳（T-03-v2 实测：P01/P09/P20/P21 四个锚点，分布均匀）。

## 5. 已知边界

- 图表为**静态 SVG 几何**，不含数据绑定；数据变化时必须手工重算坐标（按 §2 公式）。
- 图表**不替代** base 的原生 Chart 能力（`data-pptx-replace-with` 未启用），
  导出后仍是普通矢量图形（可编辑但非数据图表）。
- `donut-chart` 的 `stroke-dasharray` 方案在段数 >4 或占比极小时可能视觉不匀，
  建议 ≤4 段且最小段 ≥5%。
- 锚点页均为深色/大色块，**投影仪偏色时**对比度可能下降（未实测投影环境）。
